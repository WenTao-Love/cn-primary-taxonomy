# 🇨🇳 CN-Primary-Taxonomy · H5 移动端版本

> 面向手机端的中国小学教育知识图谱 · Canvas高性能渲染 · 触摸友好 · 零依赖

## 快速开始

### 方式一：直接打开（推荐）

项目根目录双击打开 **`cn-primary-taxonomy-h5.html`**：

- 纯前端，无需服务器
- 支持手机浏览器、微信内置浏览器、移动端Chrome
- 数据已内嵌，完全离线可用

### 方式二：本地预览开发

```bash
# 进入 h5 目录
cd h5

# 使用任意静态服务器预览
npx serve .
# 或
python -m http.server 8080
```

然后访问 `http://localhost:8080`

### 方式三：重新构建

```bash
# 从项目根目录执行
node h5/build-h5.mjs
```

## 功能特性

### 📱 移动端专属体验

| 功能 | 说明 |
|---|---|
| **底部导航** | 图谱、搜索、学习、错题、我的 - 5个核心入口 |
| **触摸手势** | 双指缩放、拖拽平移、点击选择节点 |
| **底部抽屉** | 节点详情采用原生App风格的底部弹出面板 |
| **快捷筛选** | 顶部年级/学科快捷选择条 |
| **全屏筛选** | 年级 + 学科 + 教材版本 + 视图层级组合筛选 |

### 🗺️ 知识图谱浏览

- Canvas 2D 高性能渲染（比SVG更适合移动端大量节点）
- 简化力导向布局算法，120帧内自动收敛
- 节点颜色标识学科和掌握状态
- 关系线样式区分强依赖/弱依赖

### 🔍 搜索与导航

- 实时搜索匹配知识点名称、描述、领域、教材信息
- 热门搜索快捷标签
- 搜索结果一键跳转定位

### 📚 学习系统

- **掌握状态追踪**：已掌握/学习中/未开始 三态标记
- **学习路径推荐**：基于DAG拓扑排序的智能推荐
- **交互式练习**：选择题、判断题、填空题
- **错题本**：自动记录错题，支持回顾

### 🤖 学习助手

- 自然语言输入孩子的问题
- 基于关键词匹配定位知识点
- 给出"先补什么"、"这周怎么做"的可执行建议

### 🧒 小伙伴模式

- 一键开启儿童友好模式
- 星星奖励机制
- 正向激励反馈（答错不显示"错误"，而是鼓励话语）

## 文件结构

```

├── build-h5.mjs        # 构建脚本（内嵌数据）
├── css/
│   └── style.css       # H5移动优先样式
└── js/

```

构建后输出：

```
cn-primary-taxonomy-h5.html   # 独立H5版本（~8MB，含全部数据）
```

## 设计风格

| 维度 | 设计选择 |
|---|---|
| **配色** | 明亮暖色调，适合家长和孩子共同使用 |
| **布局** | 移动优先，底部导航 + 全屏内容区 |
| **交互** | 触摸优先，手势自然 |
| **反馈** | Toast提示、底部抽屉、弹出动画 |
| **字体** | 系统原生字体栈，中文优化 |

## 性能优化

- Canvas 2D 渲染，比 SVG 更适合大量节点
- 力导向布局限制帧数和迭代次数
- 页面隐藏时停止模拟计算
- 搜索输入防抖处理
- 筛选结果缓存
- 节点数量智能限制（上限500个）
