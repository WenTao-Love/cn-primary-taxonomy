# 🇨🇳 CN-Primary-Taxonomy · H5 移动端版本

> 面向手机端的中国小学教育知识图谱 · Canvas高性能渲染 · 触摸友好

## 快速开始

### 方式一：直接打开独立版本（推荐）

项目根目录双击打开 **`cn-primary-taxonomy-h5.html`**：

- 纯前端，无需服务器
- 支持手机浏览器、微信内置浏览器、移动端Chrome
- 数据已内嵌，完全离线可用

### 方式二：开发模式

直接用浏览器打开 `h5/index.html`（需要保持项目目录结构完整，shared/ 目录必须存在）

### 方式三：重新构建

```bash
# 从项目根目录执行
node build.mjs --target=h5

# 或使用旧版构建脚本（保留）
node h5/build-h5.mjs
```

## 功能特性

### 📱 移动端专属体验

| 功能 | 说明 |
|---|---|
| **底部导航** | 图谱、搜索、学习、错题、我的 - 5个核心入口 |
| **触摸手势** | 双指缩放、拖拽平移、点击选择节点 |
| **底部抽屉** | 节点详情采用原生App风格的底部弹出面板 |
| **快捷筛选** | 顶部年级/学科快捷选择条 |
| **全屏筛选** | 年级 + 学科 + 教材版本 + 视图层级组合筛选 |

### 🗺️ 知识图谱浏览

- Canvas 2D 高性能渲染（比SVG更适合移动端大量节点）
- 简化力导向布局算法，120帧内自动收敛
- 节点颜色标识学科和掌握状态
- 关系线样式区分强依赖/弱依赖

### 🔍 搜索与导航

- 实时搜索匹配知识点名称、描述、领域、教材信息（使用 shared/js/search 模块）
- 热门搜索快捷标签
- 搜索结果一键跳转定位

### 📚 学习系统

- **掌握状态追踪**：已掌握/学习中/未开始 三态标记（分角色localStorage）
- **学习路径推荐**：基于DAG拓扑排序的智能推荐（使用 shared/js/path 模块）
- **交互式练习**：选择题、判断题、填空题
- **错题本**：自动记录错题，支持回顾

### 🤖 学习助手

- 自然语言输入孩子的问题
- 基于关键词匹配定位知识点
- 给出"先补什么"、"这周怎么做"的可执行建议

### 🧒 小伙伴模式

- 一键开启儿童友好模式
- 星星奖励机制
- 正向激励反馈（答错不显示"错误"，而是鼓励话语）

```
h5/

├── css/
│   └── style.css       # H5移动优先样式
└── js/
    └── app.js          # H5主应用逻辑
                        # - 使用 shared/ 公共模块处理数据/索引/搜索/路径/存储
                        # - 保留 Canvas 渲染、触摸手势等H5独有逻辑
```

## 与 shared/ 模块的关系

H5 版本使用 `shared/` 公共模块处理核心逻辑：

| shared 模块 | H5 中的用途 |
|---|---|
| `data-loader.js` | 加载知识点和依赖数据（自动适配路径深度） |
| `indices.js` | 构建搜索索引和依赖关系图 |
| `search.js` | 知识点搜索和筛选 |
| `path.js` | 学习路径生成和拓扑排序 |
| `storage.js` | 掌握状态、错题本、星星的持久化存储 |
| `constants.js` | 学科颜色、难度转换等常量 |
| `utils.js` | HTML转义、Toast提示等工具 |

H5 独有代码（Canvas 渲染、触摸手势、UI交互）保留在 `js/app.js` 中。

## 性能优化

- Canvas 2D 渲染，比 SVG 更适合大量节点
- 力导向布局限制帧数和迭代次数
- 页面隐藏时停止模拟计算
- 搜索输入防抖处理
- 节点数量智能限制（上限500个）
