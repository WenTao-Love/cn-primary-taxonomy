## 二、核心借鉴点

### 2.1 自适应诊断机制（最大亮点）

**cn-math-taxonomy的做法：**

1. **三态判定**：
   - **薄弱**：连续多次答错，判定为薄弱
   - **不稳**：第一题答错，但确认题答对，判定为不稳
   - **未测**：题量上限内未轮到的知识点

2. **确认题机制**：
   - 第一题答错后，不直接判定薄弱
   - 换一道同级或更基础的题确认
   - 确认题也错 → 薄弱
   - 确认题对 → 不稳（放进路径巩固，但不继续回溯）

3. **智能回溯**：
   - 薄弱知识点 → 沿依赖链往回找根因
   - 不稳知识点 → 不继续回溯，只做巩固

**反哺价值：**
- 我们的项目有4,191条依赖关系，完全具备实现自适应诊断的基础
- 目前缺少"诊断题"和"判定逻辑"
- 可以设计一套基于现有知识点的诊断系统

### 2.2 学习路径推荐

**cn-math-taxonomy的做法：**

1. **路径生成**：
   - 从根因（薄弱点）出发
   - 到目标之间还没判定为掌握的知识点
   - 按年级由低到高排
   - 同一年级里先修在前

2. **路径图可视化**：
   - 颜色区分学段（小学绿、初中蓝、高中紫）
   - 红框 = 薄弱根因
   - 橙框 = 目标
   - 实线 = 硬先修，虚线 = 软先修

**反哺价值：**
- 我们已有 `learning-paths.json`，但缺少"从薄弱点到目标"的动态路径生成
- 可以设计路径推荐算法，基于诊断结果动态生成

### 2.3 结果页设计

**cn-math-taxonomy的结果页包含：**

1. **统计概览**：已答X道，薄弱X个，不稳X个，未测X个
2. **薄弱清单**：点开每个点，看描述、掌握标准、课标条目
3. **不稳清单**：单独列一块
4. **推荐路径**：文字版路径 + 可视化路径图
5. **盲区再测**：薄弱+不稳的知识点一键重测
6. **导出功能**：分享图、JSON、PDF

**反哺价值：**
- 我们的 `weekly-newsletter.html` 和 `faq-search.html` 是内容浏览
- 缺少"诊断-结果-路径"的完整闭环
- 可以设计一个"诊断中心"页面

### 2.4 三种选题入口

1. **直接搜索**：输入知识点名称
2. **按册章浏览**：左边章，右边节，选整章或单个知识点
3. **按年级整册诊断**：适合期初摸底和期末复习

**反哺价值：**
- 我们的前端版本可以借鉴这种选题方式
- 特别是"按年级整册诊断"，非常适合期末复习场景

## 五、关键启示

### 启示1：从"知识库"到"学习系统"

cn-math-taxonomy的成功在于它不只是知识库，而是一个**学习系统**：
- 诊断（发现问题）→ 路径（规划学习）→ 巩固（解决问题）→ 再测（验证效果）

我们的项目目前停留在"知识库"阶段，需要向"学习系统"升级。

### 启示2：确认题机制值得借鉴

一道题答错不能说明问题，可能是手滑、没看清题、状态不好。确认题机制成本低、效果好。

### 启示3：路径图的颜色语义

- 绿框 = 小学，蓝框 = 初中，紫框 = 高中
- 红框 = 根因，橙框 = 目标
- 实线 = 硬先修，虚线 = 软先修

这种颜色语义非常直观，可以借鉴。

### 启示4：未测知识点的处理

题量有上限，不可能所有知识点都测。"未测"状态让家长知道"还没检查到"，而不是"没问题"。
