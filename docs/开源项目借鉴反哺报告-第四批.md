- **检索时间**：2026-11-17，来源为公开 web 搜索与 GitHub 仓库快照；未引入任何 vendor 代码，仅参照方法与公式。

## 四、P1 诊断引擎离线评测（实测）

**口径**：合成数据（种子 42，3000 名学生），仅用于结构完备性、噪声鲁棒性与题目区分度的离线自检，**不代表真实学生表现**。

| 指标 | 结果 |
|---|---|
| 引擎 gap 检测（无噪声） | P 1 · R 1 · **F1 1** |
| 引擎 gap 检测（8% 漏标 / 4% 过标） | P 0.9433 · R 0.9608 · **F1 0.952** |
| 分学科 F1（噪声口径） | 数学 0.9551 / 语文 0.941 / 科学 0.94 / 英语 0.9547 |
| BKT 掌握概率校准 | 主题 65 · 观测 195,000 · **AUC 0.8186 · MAE 0.2837** |
| 题目区分度 | basic 0.7194 / medium 0.6025 / hard 0.4831（掌握 vs 未掌握通过率差） |
| 告警 | 1 条：735 道诊断题中 **189 个 topicId 不在 topics.json**（孤儿引用，题目无法参与闭环） |

**借鉴要点**：pyBKT 的 AUC/MAE 与四参数拟合用于「掌握概率」校准；pyKT 的「统一预处理 + 留出评估」用于保证评测可复现。本项目的 BKT 为自研轻量实现（无依赖），未引入 pyBKT 代码。

## 六、P3 交互模型 / G6 / FSRS-6（实测）

### 6.1 交互模型（6 个）

| 模型 | 交互 | 自动演示 | 销毁路径 |
|---|---|---|---|
| fraction-bar 分数条 | 分子/分母滑块、×2 等值、÷2 约分 | — | — |
| number-line 数轴 | 拖拽读数、多量程/刻度 | — | — |
| triangle-angle 三角形内角 | 拖顶点实时内角与和 | — | — |
| cube-net 正方体展开图 | 点面显示相对面 | — | — |
| **angle-protractor 角的度量** | 拖橙色端点、补角 chip、角的类型判定 | ▶ 0°→180°（rAF 8s 往返） | `createAnimHost` + `stop()` |
| **decimal-grid 小数的意义** | 十分位/百分位滑块、读数换算 | ▶ 0→0.99（45ms 定时器） | `createAnimHost` + `stop()` |

- 动画基础设施：`createAnimHost()`（统一登记 rAF/定时器，stop 一次销毁）、`createAnimRef()`（可重复指向新宿主）；`render()` 开头 `stopActiveAnim()`；`node-detail.js` 组装 HTML 前调用 `visualModels.stop()`。
- 浏览器实测（家长版 standalone）：`ct_SX2S020` 读数「45° 锐角 / 由 45 个 1° 组成 / 补角 135°」；`ct_SX4X007` 读数「0.25 ＝ 25/100 ＝ 25% ，2 个 0.1 ＋ 5 个 0.01」；mock rAF/定时器验证：点击演示注册 1 个 rAF/1 个 setInterval，`stop()` 后各 cancel/clear 1 次；切换知识点时 `stop()` 被调用 3 次，无泄漏。

### 6.2 AntV G6 候选结论

- **结论：暂不引入**。G6 的 dagre 分层布局、Combo 折叠、自定义节点/边、WebGL 插件确实契合「分层 DAG + 大图折叠」方向，但当前 4275 节点用 D3 + 学科聚合降级已达可用帧率，引入会显著增大单文件体积（当前角色 standalone 已约 14–22MB）。
- **保留为候选**：若后续节点增至数万、或需要「按学段/教材分层 + Combo 折叠 + 边聚合」的图分析视图，再评估 G6（或 cytoscape compound）。本批已把该结论写入 DESIGN 与 PLAYBOOK。

### 6.3 FSRS-6 升级评估（实测）

`scripts/evaluate-fsrs-v6.mjs` 按 fsrs-rs `model_v6.rs` / `inference_v6.rs` 逐条实现 FSRS-6（21 参数、DECAY=-w[20]、FACTOR=0.9^(1/DECAY)-1），并实现官方 17→21 迁移；两环境各 3000 张卡、6~10 次复习，留出末次评估。

| 模型 | logLoss ↓ | RMSE(bins) ↓ | AUC |
|---|---|---|---|
| FSRS-4（项目现状） | 0.2691 | 0.0817 | 0.5468 |
| **FSRS-6（官方默认）** | **0.2592** | **0.0436** | 0.5149 |
| FSRS-6（项目 17 参数迁移） | 0.2798 | 0.0849 | 0.5242 |

- 两环境平均 logLoss 最优为 **FSRS-6 官方默认**；迁移版略逊于 FSRS-4（Δ+0.0107），因默认参数未针对中文小学场景校准，属预期。
- 间隔公式上两者在期望留存 0.9 下都退化为 **I(S)=S**（FACTOR 正是按 0.9^(1/DECAY)-1 定义），差异集中在记忆状态更新。
- **建议**：先采用「迁移版 FSRS-6」做**影子运行**（只记录不影响排期），累积 ≥50 条真实 reviewLog 后用 `calibrate-fsrs.mjs` 重新校准 21 参数再切换。当前**未切换**线上引擎，避免无校准参数直接影响排期。

## 七、未引入项与理由（诚实记录）

- **pyBKT / pyKT / pyedmine**：均为 Python 生态，与本项目「纯前端静态 HTML + localStorage」定位不匹配；仅吸收评测口径（AUC/MAE、留出评估、区分度），BKT 为自研轻量实现。**未引入代码**。
- **Manim**：定位为视频渲染引擎，不适合浏览器交互；仅借鉴「分步演示 + 状态驱动」思路，模型用原生 SVG + rAF/定时器自研。
- **AntV G6**：暂不引入（见 6.2），列为候选。
- **FSRS-6**：已完成评估但**未切换**线上引擎；先影子运行 + 校准，避免未校准参数影响排期。

## 八、风险与边界

1. **诊断评测为合成口径**：种子固定可复现，但不等同真实学生表现；189 个孤儿 topicId 需补题或清理，否则诊断覆盖不完整。
2. **可解释边为规则派生**：`explainSource=rule-derived`，类别/解释由规则生成，非人工逐条审核；schema 已禁止未知字段，后续可增 `curated` 精修。
3. **FSRS-6 未校准**：线上仍为 FSRS-4；FSRS-6 结论用于选型，正式切换需真实日志校准。
4. **动画销毁**：新增动画必须有 rAF/定时器销毁路径（PLAYBOOK 4.2 高风险），本批两个模型已实现并经 mock 验证。
5. **G6 未引入**：若未来引入需评估体积与离线交付约束。
