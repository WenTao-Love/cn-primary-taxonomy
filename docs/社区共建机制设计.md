# 小学教育知识图谱——社区共建机制设计

> **设计理念**：基于阮一峰科技周刊「GitHub式开放透明」理念，让教师、家长、学生共同参与知识图谱的建设，形成"活的知识图谱"。

---

## 一、设计原则

| 原则 | 说明 |
|------|------|
| **开放透明** | 所有知识内容对社区开放，版本可追溯 |
| **低门槛参与** | 即使是非技术用户也能轻松投稿 |
| **质量可控** | 审核机制确保内容质量 |
| **激励正向** | 贡献者获得积分和荣誉 |
| **教育公平** | 完全免费，帮助教育资源薄弱地区 |

| 角色 | 权限 | 审核要求 |

## 三、投稿类型

### 3.1 教学设计投稿

**适用人群**：一线教师

**投稿内容**：
- 教学设计（目标、重难点、教学过程）
- 课堂活动设计
- 板书设计
- 学生常见错误分析

**模板格式**：
```json
{
  "type": "lesson",
  "topicId": "ct_SX2S011",
  "title": "进位加法教学设计",
  "author": "张老师",
  "school": "某小学",
  "content": {
    "objectives": ["理解算理", "掌握方法"],
    "keyPoints": ["个位满十进一"],
    "difficultPoints": ["进位1的位置"],
    "process": [...],
    "blackboard": "...",
    "reflection": "..."
  }
}
```

**审核标准**：
- 符合2022新课标要求
- 教学目标明确
- 教学过程可操作
- 无科学性错误

### 3.2 辅导经验投稿

**适用人群**：家长

**投稿内容**：
- 辅导心得体会
- 孩子常见问题及解决方法
- 好用的辅导工具推荐

**模板格式**：
```json
{
  "type": "parent_experience",
  "topicId": "ct_SX2S011",
  "title": "我是这样帮孩子克服粗心",
  "author": "李妈妈",
  "content": {
    "problem": "孩子总是忘记进位",
    "solution": "用小棒演示满十进一",
    "effect": "坚持一个月后明显改善",
    "tips": "不要批评，要鼓励"
  }
}
```

**审核标准**：
- 真实经验分享
- 方法可操作
- 语言通俗易懂
- 无商业推广

### 3.3 学情数据投稿

**适用人群**：教师/家长

**投稿内容**：
- 学生常见错误类型
- 考试成绩分布
- 知识点掌握情况

**模板格式**：
```json
{
  "type": "learning_data",
  "topicId": "ct_SX2S011",
  "grade": 2,
  "schoolType": "城市小学",
  "sampleSize": 50,
  "errorRate": 0.35,
  "commonErrors": ["忘记进位", "进位1写太大"],
  "analysis": "主要原因是算理不清"
}
```

**审核标准**：
- 数据真实有效
- 样本量足够（至少30人）
- 不泄露学生隐私
- 分析合理

## 四、审核机制

### 4.1 审核流程

```
投稿 → 初审（机器）→ 复审（人工）→ 发布/驳回
```

### 4.2 初审（机器审核）

**自动检查项目**：
- 字数限制（教学设计1000-5000字，辅导经验500-2000字）
- 关键词过滤（敏感词、广告词）
- 重复检测（与已有内容比对）
- 格式检查（必填字段是否完整）

**处理时间**：即时

### 4.3 复审（人工审核）

**审核员职责**：
- 检查内容科学性
- 评估教学有效性
- 确认无政治敏感内容

**处理时间**：3个工作日内

### 4.4 申诉机制

- 被驳回的投稿可以申诉
- 申诉需说明修改内容
- 申诉处理时间：5个工作日内

## 六、反馈机制

### 6.1 内容反馈

**功能**：
- 👍 有用/👎 无用
- 💬 评论
- 🚨 举报
- 📝 纠错

**反馈处理**：
- 收到3次以上'无用'标记，自动进入复审

## 八、质量保障

### 8.1 内容质量标准

| 维度 | 标准 |
|------|------|
| **科学性** | 无知识性错误，符合课标要求 |
| **实用性** | 家长/教师可直接使用 |
| **原创性** | 重复率不超过30% |
| **时效性** | 符合当前教材版本 |

### 8.2 质量检查方式

| 方式 | 频率 | 说明 |
|------|------|------|
| 用户反馈 | 实时 | 通过点赞/无用/举报收集 |
| 定期抽检 | 每月 | 随机抽查10%的内容 |
| 专家评审 | 每季度 | 邀请专家全面评审 |
| 数据分析 | 每周 | 分析用户行为数据 |

### 8.3 内容下架机制

触发条件：
- 被证实有科学性错误
- 收到大量负面反馈
- 涉及版权纠纷
- 内容过时

处理流程：
1. 标记为"待复审"
2. 通知原作者
3. 5个工作日内完成复审
4. 确认问题后下架或修改

## 九、隐私与安全

### 9.1 隐私保护

- 不收集学生个人信息
- 投稿内容不包含学生姓名
- 用户数据加密存储
- 遵守《个人信息保护法》

### 9.2 内容安全

- 禁止发布涉及政治敏感的内容
- 禁止发布商业广告
- 禁止发布歧视性内容
- 禁止发布虚假信息

### 9.3 举报处理流程

```
举报 → 初审（24小时内）→ 处理（删除/警告/禁言）→ 反馈举报人
```
