项目简介

cn-math-taxonomy 是一个中国 K-12 教育知识图谱开源项目，覆盖数学、语文、英语、物理、化学、生物、历史、地理、科学、道德与法治等学科，从小学一年级一路到高中。

知识点不是随便拆的，而是对齐了教育部《义务教育数学课程标准（2022 年版 2025 年修订）》和《普通高中数学课程标准（2017 年版 2025 年修订）》，教材按人教版整理。其他学科也都对齐了 2022 年版课标。

而先修边，就是指知识图谱里连接两个知识点的一条有方向的线，表示"学 A 之前，需要先会 B"。

比如高中函数没学好，可能是初中二次函数没吃透，再往前，可能是小学的某个知识点。

另外，作者明确写了，这是 AI 生成的初稿，还没有经过教师审核。先修关系、题目答案都只能当线索，别当权威结论。

功能特性
01 知识图谱可视化，先修关系一目了然

打开"知识图谱"页面，三栏布局：左边按年级和章节筛知识点，中间是图谱，右边是知识点详情。

每个知识点之间用线连着，实线是硬先修（不会 A 就学不了 B），虚线是软先修。点开"配方法"，能看到它向上依赖完全平方公式，向下支撑求根公式，整个知识的来龙去脉一张图看明白。

配方法附近的先修关系图

右侧详情里有掌握标准、课标条目、样题，课标条目直接给出官方编号，做教研的同学会很有感。

02 自适应前置诊断：答错就往回追，追到小学

这是整个项目最出彩的功能。

选一个目标知识点，比如高中的"函数的概念"，系统先考目标本身。答错，就出一道同级或更简单的题；还是错，就沿着先修关系往回追——从高中追到初中，再追到小学，直到定位到真正的薄弱根因。

诊断完会给一份报告：薄弱根因、不稳的知识点、还有一条按年级从低到高排好的补学路径。

诊断结果：回溯到完全平方公式

上图的例子里，9 道题答完，2 个薄弱、1 个不稳，根因被定位到八年级的"完全平方公式"。这就是"先找到真正没学会的那一步"的意思——很多孩子高中数学吃力，病根其实在小学。

03 一站多科，英语语文物理都有独立图谱

别看仓库名叫 cn-math-taxonomy，现在早就不止数学了。

语文覆盖统编版小学一到六年级和初中七到九年级；英语从三年级到高中；物理从八年级到高中选择性必修；历史、地理、生物、化学覆盖初中；小学还有科学和道德与法治。每个学科都是独立的图谱，通过页面顶部的学科按钮切换。

英语知识图谱：现在进行时

诊断结果存在浏览器本机（localStorage），还能给孩子建档案，汇总薄弱点和盲区，一键再测。支持 PWA，加到手机桌面就能当 App 用，离线也能看。

04 结果清晰，还能分享

诊断完，会给出三样东西：

薄弱的根因
掌握不稳的知识点
一条按年级从低到高排好的补学路径

还能一键生成分享图。

数学诊断分享图
05 纯静态，数据只留本机

整个站点是纯静态的，支持离线、可以加到手机桌面。

答题进度和孩子档案，只存在浏览器本地，不上传。

不想折腾的家长，这点还挺让人放心。

快速安装、使用
方式一：直接在线用

不用装任何东西。

打开官网：https://math.pansgo.com/

想先看看效果，可以点演示：配方法诊断。

https://math.pansgo.com/diagnose/?target=cnm_221&demo=1

方式二：本地跑起来

先把代码拉下来：

git clone https://github.com/xiaoyang111222/cn-math-taxonomy.git
cd cn-math-taxonomy


页面要读取 JSON 数据，不能直接双击打开，起一个静态服务就行：

python3 -m http.server 8000


然后在浏览器里访问：

首页：http://localhost:8000/
知识图谱：http://localhost:8000/explore/
诊断：http://localhost:8000/diagnose/

英语入口，在地址后面加 ?subject=english 即可。

想校验数据，可以跑：

python3 scripts/validate.py
