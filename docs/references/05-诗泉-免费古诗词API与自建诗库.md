## 一座装在代码里的诗库

GitHub 上有个开源项目，名字叫「诗泉」。
它把中国古诗词做成了一套接口服务，程序员管这叫 API，你理解成一个「随问随答的诗库」就行。你问它，它答你，不要钱。
收录规模是近 40 万首，唐诗、宋词、元曲、诗经、楚辞都在里面。项目在 GitHub 上拿了 2800 多个星标，持续更新，近期仍有提交。

光说数字没感觉，看一眼它装了什么：

| 分类 | 收录数量 |
|---|---|
| 七言绝句 | 85,032 首 |
| 五言律诗 | 71,400 首 |
| 七言律诗 | 69,028 首 |
| 五言绝句 | 18,895 首 |
| 宋词 | 21,369 首 |
| 元曲 | 10,905 首 |
| 乐府诗 | 9,315 首 |
| 诗经 / 楚辞 | 305 / 65 首 |

《唐诗三百首》三百首，在这个库里就是个零头。

它的数据底座，是 GitHub 上一座 5.3 万 ⭐ 的中华古诗词开源数据库，把中国古诗词免费数字化的活儿，早就有人默默干完了。诗泉做的事，是给这座山修了一条人人能走的路。

## 不会代码：直接开网页

项目作者搭了个在线版，网址是 poetry.palemoky.com，浏览器打开就能用，什么都不用装。
用法很直白。能按标题搜，能按作者搜，也能拿一句话全文搜。孩子只记得「床前明月光」，把这五个字丢进去，原诗、作者全出来。
简体繁体都收在同一套库里，接口加个参数就能切换，家里老人看惯繁体字的也照顾到了。

个别网络环境要是打不开这个网址，别急，往下看，自建这条路更踏实。

## 会折腾：把诗库搬回自己家

这是诗泉最硬核的地方——一条命令，整座诗库落进你自己的机器：

```bash
docker run -d -p 1279:1279 palemoky/chinese-poetry-api:latest
```

家里那台吃灰的旧笔记本、NAS、树莓派都能跑，它同时支持 amd64 和 arm64 两种架构，硬件门槛低到可以忽略。
跑起来之后，全家手机连上家里 WiFi 就能查。不走外网，没广告，没会员弹窗，数据就躺在你自己屋里。
项目用 Go 语言写的，性能不拉胯，还内置了限流保护，不怕被人爬爆。拉镜像慢的朋友，把仓库克隆下来自己编译也行，完整的步骤仓库里都写清楚了。
别人的服务器会关，你家里的不会。

## 再进一步：给娃做个小工具

接口是开放的，肯动手的家长能玩出花。
每天早上给孩子摇一首李白的五言绝句，接口这么写：

```text
/api/v1/poems/random?author=李白&type=五言绝句
```

周末玩飞花令，摇一个带「春」字的句子当题目，全家轮流接：

```text
/api/v1/poems/random?char=春
```

一家人围着诗句抢答，比各自刷短视频强多了。条件还能叠加，朝代、体裁、作者随便组合，出题自由度很高。

不想碰代码的也别有压力，网页版查诗完全够用，这些留给家里懂行的人去折腾。
