## 四、未引入项与理由（诚实记录）

- **sigma.js / cytoscape.js / graphology-layout-forceatlas2**：未引入 vendor。理由：当前规模用「聚合 + 大图降级」已可达可用帧率，引入会显著增大产物体积（当前已约 13MB/角色）。若未来节点增至数万或需分层折叠视图，再评估 cytoscape 的 compound/expand-collapse。
- **graphrag / LightRAG / auto-ontology / OpenSPG**：均为服务端/构建期重型方案，与「纯前端静态 HTML + 本地 localStorage」定位不匹配；仅吸收其方法论（社区摘要、可回答性检查、显式 Schema）。
- **SingleFile / vite-plugin-singlefile**：本项目自研 `build.mjs` 已覆盖单文件内联与编码处理，无需引入；作为长期工程参照保留。
- **Logseq / AFFiNE / 思源**：交互范式参考，未引入代码；「反向链接列表」列为 P2 建议。
- **math-education-agent / Dynamic-Totor**：同类/相邻产品，吸收「错题本挂接 FSRS 卡片」「掌握度雷达图」建议，未引入代码。

## 五、风险与边界

1. **产物体积**：引入 sigma/cytoscape 会增大体积；当前方案优先控制体积。
2. **FSRS 替换**：已做 localStorage v3 迁移，`nextReview` 不变，避免老用户排期突变；参数当前仍为 FSRS-4 默认值（`calibrated=false`），需用真实复习日志跑 `calibrate-fsrs.mjs` 才是正式校准。
3. **⚠️ 标注项目**：K12-KGraph 仓库与授权未核实，**不得直接取用其数据**；仅作方法参照。
4. **relationType**：仅 schema / validate 就绪，数据尚未使用（全部按 prerequisite 口径）。
5. **聚合视图**：为 PC SVG 方案；H5 Canvas 未改（H5 有独立渲染与筛选）。
