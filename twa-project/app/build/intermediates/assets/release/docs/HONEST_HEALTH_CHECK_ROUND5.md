## 六、性能边界审计 ⚠️ 发现内存泄漏风险

### 6.1 事件监听器统计

| 指标 | 数值 |
|------|------|
| `addEventListener` 调用 | 102 |
| `removeEventListener` 调用 | 2 |
| 比率 | 51:1 |

**风险分析**：在单页应用中，当DOM元素被销毁并重建时（如筛选条件改变、视图切换），旧元素上的事件监听器可能无法被垃圾回收，导致内存泄漏。

### 6.2 数组操作频率

| 方法 | 调用次数 |
|------|----------|
| `.map()` | 172 |
| `.forEach()` | 107 |
| `.filter()` | 48 |

**结论**：数据密集型操作（4275个知识点 × 多次遍历）在低端移动设备上可能导致UI卡顿。

### 6.3 缺失的性能优化

| 技术 | 状态 | 潜在收益 |
|------|------|----------|
| IntersectionObserver | 未使用 | 延迟渲染不可见节点 |
| WeakMap/WeakSet | 未使用 | 防止内存泄漏 |
| Virtual DOM/scroll | 未使用 | 大数据列表渲染 |
| requestIdleCallback | 未使用 | 空闲时处理 |
