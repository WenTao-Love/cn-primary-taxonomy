# 深圳二年级一线教师校准包

## 当前状态

本仓库已为“深圳二年级语文 / 数学一线教师校准”准备好可直接审核的清单与口径，但**尚未完成真人教师签审**。  
原因很简单：代码和资料我已经落地好了，但“请老师校对”这一步必须由真实教师完成，不能由 AI 冒充。

对应待审文件：

- `data/shenzhen-g2-teacher-review.csv`

## 校准目标

请深圳地区二年级语文、数学教师重点核对以下三类信息：

1. `description`
   是否符合深圳一线课堂口径，是否“孩子能听懂、家长能理解、老师认同”
2. `commonMistakes`
   是否贴近真实作业、单元测、期中期末中的高频错误
3. `examTips`
   是否符合深圳二年级常见题型与出题表达方式

## 建议审核规则

每条知识点请给出以下结论之一：

- `通过`：可直接上线
- `微调`：方向正确，但表述需润色
- `重写`：知识点拆分、描述、易错点或考法明显不准

## 建议补充字段

如教师愿意进一步细化，建议补充：

- `teacherNote`
  一线补充说明
- `localExamStyle`
  深圳常见题面口径
- `priority`
  `P0/P1/P2`，表示是否优先修改

## 重点优先审查主题

### 语文

- 部首查字法、音序查字法
- 形近字 / 多音字
- 的、地、得
- 看图写话
- 寓言阅读

### 数学

- 100 以内进退位加减
- 表内乘法与乘法口诀
- 表内除法
- 混合运算
- 有余数除法
- 万以内数的认识

## 审核建议节奏

建议每位老师单次审核 15-20 个知识点，避免疲劳带来口径漂移。

建议流程：

1. 先审 `description`
2. 再审 `commonMistakes`
3. 最后审 `examTips`
4. 对 `重写` 项单独拉回修订

## 回填方式

推荐直接在 `data/shenzhen-g2-teacher-review.csv` 中新增以下列：

- `reviewStatus`
- `reviewer`
- `reviewDate`
- `teacherNote`

这样可以保留原始数据，又方便后续批量回写到知识点源文件。
